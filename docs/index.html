C · Profile Switching Sequence ~0.1s Fast Path

Detailed execution flow triggered during an account switch operation.

1

Concurrency Lock & Target Resolution

Acquires fcntl.flock on .agyswap.lock and resolves target slot by number, email, or alias.

2

Expired Token Guard

Compares token.expiry with system UTC clock. If expired without --force, switch is safely blocked with a renewal guide.

3

Native C API Keychain Injection

Directly modifies macOS Keychain using SecKeychainItemModifyAttributesAndData via ctypes without touching process argv.

4

Atomic Config Update & Session Notice

Atomically saves config.json and scans for running agy processes via lsof to emit session restart guidance.

D · Command Reference

agyswap [list|ls]
Displays account slots with tree-style token validity view, active session indicators, and sync timestamps.
agyswap <slot> [-r|-n] [-y]
Quick-switch profile. -r: resume last session (agy -c). -n: launch fresh session. -y: pass --dangerously-skip-permissions to agy for fully automated no-prompt workflows.
agyswap add [alias]
Registers currently active agy login session as a managed slot with Google profile metadata.
agyswap health [--json]
Overview dashboard of token expiry status across all registered profiles with warning flags.
agyswap audit
Audits and auto-corrects filesystem permissions (0700/0600) and verifies Keychain integrity.
agyswap rotate [--all | slot]
Background OAuth token refresh. --all rotates every slot simultaneously — no browser interaction required.
agyswap export [file]
Exports slot metadata to JSON format for migration (sensitive live tokens excluded for security).
agyswap import <file>
Imports slot metadata from JSON with automatic slot conflict resolution.
agyswap ctx [bench|map|state|clean]
AST Codebase Mapping & Token Optimizer. bench [--golden] [--json|-md]: measure compression, or run the 10-language oracle regression. map/state: compact context snapshots. clean: sync both before /clear.
agyswap alias [slot] [name] [--unset]
Standalone alias management — list every aliased slot, set a new alias, or clear one. Same rename engine as agyswap rename, exposed as its own command.
agyswap enable|disable <slot>
Holds a slot out of blind rotation (agyswap switch with no target) without deleting its credentials. Explicit agyswap switch <slot> still works on a disabled slot.
agyswap quota [slot] [--refresh] [--json]
Per-account, per-model Gemini API quota — remaining %, reset time. TTL-cached (45s) and merge-safe; --refresh bypasses the cache.
agyswap tui / agyswap watch
Live, keyboard-driven terminal dashboard with real-time per-model quota bars (rich + textual). watch jumps straight into the live-monitor view.
agyswap completion <shell>
Generates shell auto-completion scripts for zsh, bash, and fish with dynamic slot completion.

H · POSIX Storage Layout

        

~/.agyswap/                            # Mode 0700 (Owner rwx only)
├── config.json                        # Mode 0600 (active_slot, accounts metadata)
├── .agyswap.lock                      # Mode 0600 (flock concurrency barrier)
├── quota_cache.json                   # Mode 0600 (TTL-cached Gemini quota, merge-safe)
├── dashboard.html                     # Mode 0600 (generated by 'agyswap viz')
├── slots/                             # Mode 0700 (Isolated slot directory)
│   ├── slot-1.json                    # Mode 0600 (OAuth token credentials)
│   └── slot-2.json                    # Mode 0600
└── backup/                            # Mode 0700 (Directory)
    └── config-YYYYMMDD-HHMMSS.json    # Mode 0600 (Rolling automated backups)

J · Troubleshooting FAQ

        

          
Do running agy CLI sessions switch immediately? +

          
macOS caches Keychain reads in memory for short durations. While the Keychain is updated instantly in ~0.1s, starting a new terminal prompt or restarting existing agy sessions guarantees active credential activation.

        

        

          
How do I safely migrate to a new Mac? +

          
Run agyswap export backup.json on your old Mac. On your new Mac, run agyswap import backup.json. Live tokens are excluded from export for security; simply log into each profile once via agy and run agyswap sync.

        

        

          
What should I do if a token expires? +

          
Run agyswap rotate <slot> to initiate a token refresh, or log into the expired account using agy and run agyswap sync.

        

        

          
My data used to live at ~/.agy-swap — where did it go? +

          
Moved automatically to ~/.agyswap/ (no hyphen) the first time you ran any command after upgrading — the old hyphenated path collided with an unrelated third-party tool of a similar name. Only agyswap's own files (config, slots, backups) were moved; nothing else in the old directory was touched.

        

        

          
Why does `agyswap tui` say it can't load the TUI module? +

          
tui/watch need the rich and textual packages. Pip/pipx installs get them automatically; Homebrew and the curl installer don't vendor them, so run pip3 install --user rich textual once. Every other command works without them.

        

        

          
What's the difference between `disable` and `remove`? +

          
agyswap disable <slot> just holds an account out of blind rotation (agyswap switch with no target skips it) — its credentials stay intact and agyswap switch <slot> still switches to it explicitly. agyswap remove <slot> deletes the slot's stored token entirely.
